АСУУЛТУУД
1. PCB гэж юу вэ?
- PCB гэж Process Control Block гэсэн үгсийн товчлол бөгөөд энэ нь процесс тус бүрд хамаарах мэдээллийг хадгалдаг өгөгдлийн бүтэц юм.
2. Process state ямар үүрэгтэй вэ?
- Process state нь ямар нэг процессийн тухайн үеийн төлөв байдлыг тодорхойлдог. Running, waiting, ready, terminated гэх мэт төлөв байдэг.
3. READY ба RUNNING төлөвийн ялгаа юу вэ?
- Процесс нь процессорт хуваарилагдаж ажиллахад бэлэн байвал ready, ажиллаж байвал running төлөв юм.
4. WAITING төлөв хэзээ үүсгэдэг вэ?
- Процесс нь ямар нэг зүйл болох эсвэл дуусахыг хүлээх хэрэгтэй үед waiting төлөвт шилждэг.
5. Priority scheduling ямар зарчмаар ажилладаг вэ?
- Priority scheduling нь процессуудад олгогдсон priority буюу эрэмбээр нь жагсааж хамгийн урд байгаа нь CPU-г түрүүлж хэрэглэдэг.
6. Context switching гэж юу вэ?
- CPU нэг процесс дээр ажиллаж байгаад өөр процесс руу шилжихдээ өмнөх процессын төлөвийг хадгалж, шинэ прогцессыг ажиллуулах үйл явц юм.
7. Context switching яагаад overhead үүсгэдэг вэ?
- Учир нь төлөв шилжилт хийхэд систем нь зөвхөн хадгалах, ачааллуулах үйлдлүүдийг хийдэг. Иймээс overhead үүсдэг.
8. Энэ лабораторийн симуляци бодит үйлдлийн системээс юугаараа ялгаатай вэ?
- Симуляци нь программ дээр ажилладаг. Харим бодит үйлдлийн систем нь бодит төхөөрөмж дээр ажиллаж, процесс, тасалдал гэх мэт зүйлс нь
