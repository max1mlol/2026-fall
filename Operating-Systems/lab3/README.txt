Лабораторийн Ажил №3

ЗОРИЛГО
Энэхүү лабораторийн ажлаар үйлдлийн системийн процесс ба Process Control Block(PCB)-н үндсэн ойлголтыг
програмчлалын түвшинд ойлгох юм. PCB бүтэц ашиглан процессийн төлөв болон гүйцэтгэлийн мэдээллийг
хадгалах, шинэчлэх механизмын хэрэгжүүлэлтийг хийж, Round-Robin симуляци болон цэсээр удирдах зарчмыг туршина.

ШААРДЛАГА
1. struct PCB бүтцийг process_id, priority, state, process_counter талбаруудтай зарлана.
2. Өөр өөр логик бүхий 3 процессыг тус тусад нь компайл хийнэ.
3. process_counter болон state-г алхам бүрд шинэчилнэ.
4. Lab3.c-г ажиллуулж Round-Robin симуляцийг хэрэгжүүлнэ6

ҮНДСЭН ОЙЛГОЛТ
- Process Control Block(PCB): Үйлдлийн системээс процессыг удирдах8 төлөвийг нь хадгалахад ашигладаг 
  үндсэн өгөгдлийн бүтэц.
- Process State: Процессын одоогийн төлөв
- Process Counter: Процессын гүйцэтгэлийн тоолуур эсвэл давталтын тоо.
- Round-Robin Simulation: Олон процессыг дарааллын дагуу ээлжлэн тодорхой хугацаанд ажиллуулах симуляци.

ФАЙЛЫН БҮТЭЦ
Lab3/
    Process1.c  #Санамсаргүй байдлаар тоо сонгож өсөх эрэмбээр эрэмбэлнэ.
    Process2.c  #Хоёр хэмжээст матриц үүсгэж хооронд нь нэмнэ.
    Process3.c  #Тэмдэгт мөрийн ижил тэмдэгтийн давтамж тоолох.
    Lab3.c      #Нэгтгэсэн программ
    README.txt  #Тайлан болон программыг ажиллуулах заавар.

АЖИЛЛУУЛАХ ЗААВАР
1. Файлуудыг компайл хийх:
    gcc Process1.c -o process1
    gcc Process2.c -o process2
    gcc Process3.c -o process3
    gcc Lab3.c -o lab3
2. Процессуудыг ажиллуулах:
    ./process1
    ./process2
    ./process3
3. Нэгтгэсэн программыг ажиллуулах:
    ./lab3

ДҮГНЭЛТ
Энэхүү лабораторийн ажлаар C хэл ашиглан PCB бүтэц тодорхойлон, олон процессын төлөв болон гүйцэтгэлийн 
тоолуурыг симуляцийн түвшинд удирдаж сурсан. Процес бүр ажиллахдаа READY-с RUN болж, process_counter 
шинэчлэгдэнэ. Дараагийн алхамд буцаж READY төлөвт шилжинэ. Мөн Round-Robin-р процессуудыг ээлжлэн 
ажиллуулахыг хэрэгжүүллээ.
